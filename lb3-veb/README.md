Цей проєкт демонструє переведення статичного сайту на архітектуру з єдиною точкою входу (Front Controller) на PHP та використання AJAX для асинхронного завантаження даних.

## Як запустити цей проєкт локально:

1. Завантажте цей репозиторій (або зробіть `git clone`) у папку вашого локального сервера (наприклад, `htdocs` для XAMPP або `www` для Laragon).
2. Переконайтеся, що локальний сервер з підтримкою PHP (Apache/Nginx) запущено.
3. Відкрийте браузер та перейдіть за локальною адресою папки, наприклад:
   `http://localhost/назва_папки/index.php`
4. Для перевірки роботи API перейдіть на `http://localhost/назва_папки/api.php`

## Що було реалізовано:
- **`index.php`** — маршрутизатор (Front Controller), який динамічно підвантажує `.html` шаблони через GET-параметр `?page=...`
- **`api.php`** — бекенд-ендпоінт, що віддає масив товарів у форматі JSON.
- **`shop.js`** — фронтенд (Vue.js), який отримує список товарів через `fetch('api.php')` замість використання захардкоджених даних.
